# User Documentation

This folder contains user-facing documentation for Open Model Gateway. It is
written for operators, admins, and day-to-day users of the admin/user portals.

## Audience

- **Operators**: set up models, budgets, and rate limits.
- **Admins**: manage tenants, users, and keys.
- **End users**: issue personal keys and review usage.

## Contents

- `user_docs/getting-started.md` - UI entry points, login, and navigation.
- `user_docs/models.md` - Add models to the catalog and validate them.
- `user_docs/tenants-and-users.md` - Create tenants, invite users, manage roles.
- `user_docs/api-keys.md` - Issue API keys and admin tokens; how to use them.
- `user_docs/budgets-and-rate-limits.md` - Budgets, rate limits, alerts.

## Related References

- `docs/admin/guide.md` - Operator and deployment guide.
- `docs/admin/model-catalog-examples.md` - Full model catalog examples.
- `docs/runtime/config.md` - Router configuration reference.
- `docs/openapi/openapi.yaml` - API surface and schemas.

## Updating These Docs

- Keep examples aligned with the current UI labels.
- Prefer copy/pasteable steps and short command snippets.
- Link back to authoritative references when details are complex.
